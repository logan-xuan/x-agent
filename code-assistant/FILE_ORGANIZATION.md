# FILE_ORGANIZATION.md - 工作空间文件组织规范

本文件说明工作空间中各文件的用途和组织方式。

## 核心文件

| 文件 | 用途 | 读取时机 |
|------|------|----------|
| `AGENTS.md` | 工作空间使用指南、安全准则、记忆系统说明 | 每次会话开始 |
| `SPIRIT.md` | AI 人格设定（角色、性格、价值观、行为准则） | 每次会话开始 |
| `IDENTITY.md` | 身份信息（名字、存在形式、气质、emoji） | 每次会话开始 |
| `OWNER.md` | 用户画像（姓名、职业、兴趣、偏好） | 每次会话开始 |
| `MEMORY.md` | 长期记忆精华（跨会话的重要信息摘要） | 仅主会话中读取 |
| `TOOLS.md` | 可用工具定义和使用规则 | 需要使用工具时 |
| `HEARTBEAT.md` | 定期心跳任务配置 | 心跳触发时 |
| `BOOTSTRAP.md` | 首次启动引导（完成后删除） | 仅首次启动 |

## 记忆目录

```
memory/
├── YYYY-MM-DD.md   # 每日原始日志（按日期命名）
└── ...
```

- **每日文件**：记录当天的原始事件、决策、上下文
- **MEMORY.md**：从每日文件中提炼的长期记忆精华

## 文件更新规则

- `SPIRIT.md` / `IDENTITY.md` / `OWNER.md`：在了解更多信息后随时更新
- `MEMORY.md`：定期从每日文件中提炼，保持精简
- `memory/YYYY-MM-DD.md`：每日追加，不修改历史记录
- `TOOLS.md`：新增工具或修改工具配置时更新
- `HEARTBEAT.md`：需要定期任务时更新

## 扩展文件

根据需要可在工作空间中添加：
- `SKILLS.md`：已安装的技能模块说明
- `PROJECTS.md`：正在进行的项目列表
- `NOTES.md`：临时笔记和草稿
