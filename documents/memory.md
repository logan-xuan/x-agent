# 记忆系统设计文档

## 概述
记忆系统是 AI 助手的核心组件，负责实现"自我认知"与"记忆演化能力"。该系统通过结构化的记忆管理，使 AI 能够记住过往交互、学习经验并形成个性化的知识体系。

## 系统架构

### 记忆类型
1. **短期记忆** - 当前会话内的上下文
2. **长期记忆** - 跨会话的持久化记忆
3. **语义记忆** - 结构化知识（事实、概念）
4. **程序记忆** - 技能和模式（如何执行任务）
5. **自传记忆** - 与用户的交互历史

### 存储方案
- **SQLite-VSS** 作为向量数据库存储语义记忆
- **SQLite** 存储结构化记忆（对话历史、元数据）
- **Markdown 文件** 存储用户日志和重要记忆
- **缓存层** 存储活跃记忆片段

## 实现细节

### 记忆编码
- 使用嵌入模型将文本转换为向量表示
- 支持多种编码策略（句子级、段落级、主题级）
- 自动提取关键词和实体

### 记忆压缩
- 定期对旧记忆进行摘要压缩
- 保留关键信息，减少存储占用
- 维护记忆的关联性

### 记忆新鲜度
- 追踪记忆的访问频率和时间
- 优先保留高频访问的记忆
- 实现记忆衰减机制

## API 接口

### 记忆存储
```python
def store_memory(content: str, memory_type: str, metadata: dict = None) -> str
```
存储新的记忆条目，返回记忆ID

### 记忆检索
```python
def retrieve_memory(query: str, limit: int = 5, filters: dict = None) -> List[MemoryItem]
```
基于查询语句检索相关记忆

### 记忆聚合
```python
def aggregate_memories(session_id: str = None, time_range: tuple = None) -> dict
```
聚合特定范围内的记忆

## 自我认知机制

### 个人资料管理
- 维护助手的自我描述
- 记录能力边界和限制
- 更新知识状态

### 用户画像
- 存储用户偏好和习惯
- 记录用户的历史行为
- 维护个性化设置

## 安全与隐私

### 权限控制
- 限制对敏感记忆的访问
- 实现记忆访问日志
- 支持记忆删除和匿名化

### 隐私保护
- 加密存储敏感信息
- 支持选择性遗忘
- 符合数据保护法规

## 性能优化

### 缓存策略
- 分层缓存机制
- 预加载常用记忆
- 智能缓存淘汰

### 查询优化
- 向量索引加速相似度搜索
- 多级过滤减少计算量
- 异步批处理提高吞吐量

## 监控与维护

### 健康检查
- 监控记忆库完整性
- 检测异常访问模式
- 评估记忆检索质量

### 自动维护
- 定期清理过期记忆
- 优化数据库性能
- 备份重要记忆
