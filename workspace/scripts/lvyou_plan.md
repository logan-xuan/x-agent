# 杭州到西安五日游行程安排

## 第一天：抵达西安，市区游览
- 上午：从杭州出发，乘坐飞机（约2小时20分钟）抵达西安咸阳国际机场
- 下午：入住酒店，稍作休息
- 傍晚：游览钟鼓楼广场，欣赏古建筑夜景，品尝回民街小吃
- 住宿：钟楼附近酒店

## 第二天：兵马俑 + 华清宫
- 上午：前往临潼区参观世界文化遗产【秦始皇兵马俑博物馆】（游览约3小时）
- 下午：游览【华清宫】，感受唐玄宗与杨贵妃的爱情故事及西安事变历史（游览约2.5小时）
- 晚上：观看《长恨歌》实景演出（可选）
- 住宿：西安市内酒店

## 第三天：西安城墙 + 陕西历史博物馆
- 上午：参观【西安城墙】，骑行或步行体验完整的明代城垣（游览约2小时）
- 下午：游览【陕西历史博物馆】，了解陕西丰富的历史文化（游览约2.5小时）
- 晚上：游览大唐不夜城，感受盛唐文化氛围
- 住宿：西安市内酒店

## 第四天：大雁塔 + 大兴善寺
- 上午：参观【大雁塔】及其北广场音乐喷泉（游览约2小时）
- 下午：游览【大兴善寺】，体验佛教文化（游览约1小时）
- 傍晚：参观【大唐芙蓉园】，欣赏园林景观
- 住宿：西安市内酒店

## 第五天：返程
- 上午：自由活动，购买特产
- 下午：前往机场，返回杭州

## 旅行贴士
- 交通：市内建议使用地铁和出租车，去临潼可乘坐旅游专线
- 美食：肉夹馍、凉皮、羊肉泡馍、biáng biáng面、葫芦头等
- 住宿：建议选择钟楼、大雁塔附近，交通便利
- 门票：兵马俑120元，华清宫120元，西安城墙54元，陕西历史博物馆免费（需预约）
