# x-agent2 项目 Claude Code 开发指南

## 项目概述
本指南基于 x-agent2 项目的架构设计文档，旨在规范和指导 Claude Code 在项目开发过程中的使用，确保开发工作遵循既定的技术架构和最佳实践。

## 项目目标
x-agent2 是一个多功能 Agent 智能体个人助理，具备以下核心能力：
- 编写代码
- 自然语言聊天（对话）
- 扩展技能（如制作 PPT、处理文档，通过 workspace 文件夹由用户自定义扩展 skill）
- Web 搜索
- Chrome 浏览器自动化操作
- 执行本地 CLI 命令
- 访问本地文件系统
- Cron 定时任务管理

## 技术架构

### 技术栈
- 采用 TypeScript + Python 混合架构
- 后端使用 Python FastAPI
- 前端使用 React + TypeScript
- 采用模块化 + 插件式架构，便于功能扩展

### 架构分层
项目采用分层架构设计：
1. **Expression（表达层）** - 用户界面和消息渠道
2. **Gateway（网关接入层）** - 消息传递和会话管理
3. **Agent Core（智能体核心）** - 控制中心和任务调度
4. **Tools（工具库）** - 工具执行层
5. **DBM（数据库存储与管理）** - 数据持久化

## 开发最佳实践

### 1. Agent Core 开发原则
- 实现 LLM 推理引擎
- 构建 Context Engineering（上下文工程管理）
- 开发 Task Planner（任务规划）
- 设计 Skill Router（技能路由）
- 集成 Memory System（记忆系统）
- 实现 Security Guard（安全守卫）

### 2. 上下文管理
- 不要将所有历史信息传递给 LLM
- 只传递最精准、最关键的上下文
- 对每个会话进行交互记录并同步到 SQLite 便于查询
- 合理使用 Conversation Compression 技术

### 3. 记忆系统
- 实现 AI 助手的"自我认知"与"记忆演化能力"
- 采用 SQLite-VSS 作为向量数据库
- 使用 Markdown 文件存储用户日志记忆
- 设计合理的记忆演进机制

### 4. 工具开发
- 采用模块化、可插拔的工具设计
- 系统级工具与用户自定义技能分离
- 在 workspace 目录下支持用户自定义技能扩展
- 包含但不限于：Cron 管理、Web 搜索、代码解释器、文件系统访问、命令执行器等

### 5. SubAgent 开发原则
- SubAgent 默认不开启，通过显性命令 `/subagent` 启动
- 按需启动以避免资源浪费
- 为每个子代理精准投喂最小化 Prompt
- 提升识别精度，降低 Token 消耗
- 实现 LLM + Tools + MCP + SubAgent 协同工作

### 6. 安全性原则
- 实现安全的命令执行模块
- 默认只允许执行当前用户权限下的操作
- 实施权限控制和安全验证

### 7. 通信与监控
- 实现心跳机制监控长任务执行
- 支持 WebSocket 和 REST API 通信
- 集成实时日志流显示
- 实现任务进度可视化

## 配置管理
