# x-browser-to-summary

此技能指导 AI 如何高效地使用浏览器工具获取信息并产出高质量的总结。

## 核心工作流

1. **启动浏览器任务**：使用 `task` 工具启动 `Browser` subagent。
2. **获取内容**：明确要求 subagent 读取目标 URL 的完整内容（如 README, 官方文档, 博客文章等）。
3. **结构化处理**：根据获取的原始文本，按照预定义的模版进行归纳。
4. **输出总结**：将处理后的结果以清晰的 Markdown 格式呈现给用户。

## 总结模版建议

在生成总结时，应包含以下维度（如适用）：
- **项目/内容概述**：一句话定义它是什么。
- **核心功能/概念**：列出关键点或核心逻辑。
- **安装/使用步骤**：简明扼要的操作指南。
- **核心优势/价值**：为什么使用它。
- **参考链接**：原始链接及相关资源。

## 注意事项
- **语言对齐**：始终使用用户偏好的语言进行总结（除非另有说明）。
- **简洁性**：避免冗长的叙述，优先使用列表和加粗字体。
- **准确性**：确保安装命令和核心术语的准确性。
